## Reference repositories

Seven public fraud-detection repositories analysed by Roberto Chiocca on 2026-11-09. The license and the use are in the table. Any code adapted from one of them goes into [`docs/en/code-origin.md`](code-origin.md), with an origin header and the original license, as was done with Carchuna and DireitoAberto. So far, no code from these repositories has been copied: the engine card, the dependency audit in CI and the demo mode use only the ideas.
