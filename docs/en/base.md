Generated by `python -m chiocca.relatorio_base` from `data/base/empresa_ano.csv` (outside git). Do not edit by hand: a test compares this file with the script output.

Base built on 2026-11-07, with the raw files checked against `data/manifesto_brutos.csv`. Fiscal years 2010 to 2025. No signal was computed in this phase.

## Rules applied

- **Point-in-time version:** the latest one filed by the cut-off date, the last day of the fourth month after the fiscal year-end (pre-registration, section 3, and amendment 5).
- **Consolidated statements when available; otherwise, individual** (amendment 5).
- **Point-in-time version older than the open-data one:** taken from the ENET HTML view, for consolidated statements only (amendment 8). An empty cell counts as 0.
- **Repeated account in the same statement:** with equal values, one is kept; with different values, the company-year is not computable (amendment 8).
- **Groups:** frozen rule of part 4.1 of the reconnaissance, with the FCA version filed by the cut-off (amendment 7).
- **Two readings of each fiscal year:** the original (ÚLTIMO in that year's DFP) and the restated one (PENÚLTIMO in the next year's DFP), each in the version of its own cut-off date.
