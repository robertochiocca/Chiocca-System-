# Temporal storage and engine v1 on any date (Phase C1)

Generated by `python -m chiocca.v2.invariante` from `docs/invariante_numeros.json`. Do not edit by hand: a test compares this file with the script output. Aggregate numbers only; no company is named.

## The store

- Parquet queried through DuckDB (`chiocca/v2/armazem.py`), built offline from `data/brutos/cvm` (checked by hash) and the ENET cache, in `data/armazem/`, outside git. Fiscal years 2010 to 2023; no sealed fiscal year goes in.
- Tables: `versoes` (12,372 DFP versions, with the filing date), `contas` (7,550,288 rows, from open data and from 341 ENET documents), `fca` (22,203 versions) and `cadastro` (2,679 rows). `manifesto.json` keeps the SHA-256 hash of every source file.
- For documents filed after 2024-12-31, the store keeps metadata only: version, filing date and which statements exist, with no account and no value (14 documents). Engine v1's `como_era` uses this structure of the latest version to know whether a consolidated statement exists (the ENET route, amendment 8) and to name the ENET cash flow statement; with a reference date up to 2024-12-31, that version's values are never read.
- `FontesArmazem` has the same interface as the raw files (`chiocca.cvm.Fontes`): engine v1 runs on the store without any change.

## Engine v1 on the date

- `ExercicioNaData` (`chiocca/v2/na_data.py`): one company in one fiscal year, as it was on the reference date, with the version used, only the versions filed by the date, the origin (open data or ENET) and the document link. The date goes through the 2011-04-30 to 2024-12-31 range, and the fiscal year through the seal.
- Cross-section on the date: the same study 1 functions (`como_era`, `grupos`, `sinais_amostra`), with the year's deciles recomputed only with the companies whose version was public on the date.
- Product layer, next to the engine and without changing any of its values: the `produto_nao_calculaveis` column lists the signals the product shows as "not computable" because of an unfilled balance sheet.
